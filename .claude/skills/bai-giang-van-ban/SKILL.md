# Bài giảng văn bản + ảnh & biểu đồ

## Khi nào dùng

User chọn **văn bản minh họa** / longread / handout / tài liệu học kèm hình.

## Quy trình

1. Brief: chủ đề, đối tượng, độ dài (vd 1200-2000 chữ), ngôn ngữ.
2. Research → khung: hook, 3-5 mục, ví dụ, tóm tắt, bài tập.
3. Viết bài đầy đủ, giọng rõ, đoạn ngắn.
4. Chèn chỗ **[BIỂU ĐỒ]** với dữ liệu dạng bảng markdown (không bịa số không nguồn).
5. Chỗ **[ẢNH]** kèm prompt ảnh; nếu ChatGPT/Gemini image sẵn → `javis_generate_image`, lưu `attachments/`, embed `![](attachments/...)`.
6. Lưu `exports/bai-giang/<slug>/bai-doc.md`.

## Kiểm chứng

Có ít nhất 1 ví dụ cụ thể, 1 hoạt động luyện, 1 hình hoặc biểu đồ có chú thích.
