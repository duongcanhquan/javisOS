# Copy framework

Viết `COPY.md` trước HTML. Mỗi khối đủ để dán thẳng vào template.

## Cấu trúc

```markdown
# COPY — <slug>

## SEO
- title: (≤60 ký tự)
- description: (≤155 ký tự)
- og_title / og_description: (có thể trùng)

## Nav
- brand:
- links: [Tính năng, Cách dùng, Đánh giá, Giá]
- CTA nav:

## Hero
- eyebrow: (tuỳ chọn)
- h1:
- sub: (1–2 câu)
- CTA primary:
- CTA secondary: (tuỳ chọn)
- trust line: (vd «Dùng bởi 120 shop» - chỉ số thật)

## Logo strip (tuỳ)
- nhãn: «Được tin bởi»
- items: …

## Features (3–6)
| icon gợi ý | title | body |
|---|---|---|

## How it works (3 bước)
1. …
2. …
3. …

## Social proof
- quote:
- author / role:
(thêm 1–2 nếu có)

## Pricing (nếu brief có)
- plans: …

## FAQ (3–5)
- Q / A

## Final CTA
- h2:
- sub:
- button:

## Footer
- tagline ngắn
- links pháp lý placeholder (#) nếu chưa có URL
```

## Luật viết

- Tiếng Việt mặc định trừ brief yêu cầu khác.
- Active voice; một ý một câu; tránh sáo «giải pháp toàn diện».
- Không bịa case study / chứng chỉ / % chuyển đổi.
- CTA cùng một động từ xuyên suốt (vd «Dùng thử miễn phí»).
- Headline không nhét từ khoá SEO đến mức khó đọc; SEO để meta + 1 H2 tự nhiên.

## Sau khi có COPY.md

Đề xuất layout (`design-catalog.md`) khớp độ dài copy (nhiều giá → layout có pricing;
chỉ waitlist → layout tối giản).
