# Catalog công cụ Marketing (rút gọn)

Giúp **chọn nhóm công cụ** đúng việc - không liệt kê hàng trăm URL từ awesome-list.

## When to use

- «Dùng tool gì cho SEO/email/ads?», so sánh loại công cụ, stack MKT mới.
- Không thay skill chuyên môn (`kiem-tra-seo`, `bao-cao-facebook-ads`, `lang-nghe-mxh`…).

## Nguyên tắc chọn

1. **Một việc / một lớp** - analytics riêng, ads riêng; tránh «all-in-one» nếu chỉ cần 1 job.
2. **Dữ liệu đi về đâu** - ưu tiên tool export được + nối MCP/Javis khi có.
3. **Chi phí & team** - free tier đủ học; trả phí khi có owner dùng hàng tuần.
4. **Tuân thủ** - email/SMS: consent; crawl: robots; ads: policy nền tảng.

## Nhóm công cụ (catalog ngắn)

| Nhóm | Việc điển hình | Gợi ý loại (không khóa vendor) |
|------|----------------|--------------------------------|
| SEO | Audit, rank, crawl | Search Console, crawler (Screaming Frog / advertools), schema |
| Content | Brief, lịch, CMS | Docs/Notion + skill `viet-bai-seo` / CMS sẵn có |
| Email | ESP, automation | ESP có API + skill `viet-email-marketing` (soạn) |
| Ads | Meta/Google/LinkedIn | Ads Manager + `quang-cao-da-kenh` / `bao-cao-facebook-ads` |
| Analytics | Web + sự kiện | GA4 / Plausible / tương đương + MCP nếu có |
| Social listening | Mentions, trend | Tool listen + `lang-nghe-mxh` / `y-tuong-noi-dung-tu-trend` |
| CRO / research | Heatmap, survey | Hotjar-class / form survey + `toi-uu-chuyen-doi-cro` |
| Design / landing | Page builder | Skill `landing-page` trước khi mua builder |

Khi user hỏi vendor cụ thể: nêu 2-3 lựa chọn phổ biến + tiêu chí chọn; **không** dump toàn bộ awesome-list.

## Đầu ra

`exports/marketing/<slug>/tool-stack.md`: nhu cầu → nhóm → 1 lựa chọn đề xuất + lý do + tích hợp Javis/MCP nếu có.
