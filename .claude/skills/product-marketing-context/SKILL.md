# Product marketing context

Tài liệu nền định vị / ICP / promise để mọi skill Marketing khác không hỏi lại từ đầu.

## When to use

- User muốn «định vị», «ICP», «đối tượng khách», «product context», «marketing context».
- Bắt đầu dự án MKT mới trước khi viết copy / ads / email / launch.
- Skill CRO/copy/email/ads/launch: **đọc file này trước** nếu đã có.

## Đường dẫn chuẩn (Javis)

Canonical: `wiki/product-marketing.md` hoặc `exports/marketing/product-marketing.md`.

Fallback cũ (chỉ đọc, rồi đề nghị chuyển sang canonical): `.agents/product-marketing.md`, `product-marketing-context.md`.

## Quy trình

1. Kiểm file đã có chưa. Có → tóm tắt + hỏi mục cần cập nhật. Chưa → hỏi auto-draft từ README/landing/wiki hay điền từng mục.
2. Điền các mục (chỉ thu thập phần còn thiếu):
   - **Sản phẩm** - tên, 1 câu nó là gì, khác biệt chính
   - **ICP** - ai mua, vai trò, quy mô, pain chính (ngôn ngữ khách)
   - **Promise** - kết quả / chuyển đổi cốt lõi
   - **Bằng chứng** - số, case, social proof (không bịa)
   - **Đối thủ / thay thế** - 2-4 lựa chọn khách so sánh
   - **Tone & cấm** - giọng nói, từ tránh
   - **CTA mặc định** - hành động chính (demo, mua, đăng ký…)
3. Lưu markdown ngắn; bump **version** + 1 dòng changelog khi sửa lớn.
4. Báo path; skill MKT sau này mở file này trước khi hỏi lại.
