# Quảng cáo đa kênh

Khung chiến dịch paid + góc creative. Số liệu Meta thật vẫn qua `bao-cao-facebook-ads` khi có MCP.

## When to use

- Lên / tối ưu Google Ads, Meta, LinkedIn, X (chiến lược, audience, bid, budget, kill rule).
- Sinh hàng loạt headline / primary text / RSA / hook creative.
- Không thay báo cáo số Meta đã có skill riêng.

## Trước khi làm

1. Đọc `product-marketing-context` nếu có.
2. Mục tiêu (awareness / lead / sale), CPA/ROAS mục tiêu, ngân sách, landing URL, ICP, dữ liệu pixel hiện có.

## Khung chiến dịch

- **Funnel**: prospecting → retargeting; message khớp giai đoạn nhận biết.
- **Cấu trúc**: campaign / ad set / ad rõ; tránh trộn mục tiêu trong một set.
- **Audience**: interest / lookalike / keyword / ABM - ghi giả thuyết, không bịa size.
- **Landing**: message match với ad; nếu yếu → `toi-uu-chuyen-doi-cro` / `landing-page`.
- **Kill rule**: khi nào tắt creative / tăng budget (ngưỡng user đặt hoặc đề xuất có điều kiện).

## Creative (góc nhanh)

- 5-10 góc: pain, outcome, proof, objection, competitor-alternative, demo.
- Mỗi góc: hook + body ngắn + CTA; biến thể A/B.
- Platform note: Meta primary text; Google RSA 15/4; LinkedIn chuyên nghiệp hơn.
- Lưu `exports/marketing/<slug>/ads-plan.md` + `ad-creative.md`.

## Số thật

- Meta đã kết nối → nạp `bao-cao-facebook-ads` / `tong-ket-facebook`.
- Không bịa ROAS/CPA. Không tự tạo campaign trên MCP trừ khi user lệnh + quyền phù hợp.
