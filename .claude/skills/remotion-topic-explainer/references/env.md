# Biến môi trường (.env trong project Remotion)

```env
TTS_PROVIDER=edge
TTS_OUTPUT_DIR=public/audio

EDGE_TTS_VOICE=vi-VN-HoaiMyNeural
EDGE_TTS_RATE=+10%

# Chỉ khi đã cài CIT Voice Studio
# TTS_PROVIDER=cit
# CIT_TTS_BASE_URL=http://127.0.0.1:8001
# CIT_TTS_VOICE=Hải Đăng
# CIT_TTS_SPEED=1.1

CHANNEL_NAME="VietMy OS"
```

Đầy đủ hơn: `.env.example` trong vendor
`$JAVIS_STATE_DIR/vendor/remotion-cuongit-template`.
