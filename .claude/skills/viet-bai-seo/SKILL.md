# Viết bài SEO

## Khi nào dùng

User cần **bài viết web / blog / landing section** tối ưu tìm kiếm, vẫn đọc được như người viết.

## Quy trình

1. Brief: chủ đề, từ khóa chính + phụ, đối tượng, độ dài (mặc định 1000-1500 chữ), CTA, ngôn ngữ.
2. Research ngắn (`deep-research` breadth≈3 depth≈2) nếu thiếu fact/góc cạnh tranh.
3. Outline: H1, 4-7 H2, chỗ FAQ nếu hợp.
4. Viết bài: đoạn ngắn, ví dụ cụ thể, từ khóa tự nhiên (không nhồi).
5. Kèm khối SEO:
   - Title tag (≤60)
   - Meta description (≤155)
   - URL slug gợi ý
   - 3 biến thể OG title
6. Lưu `exports/marketing/<slug>/bai-seo.md`.

## Kiểm chứng

Có H1 đúng 1, ≥1 ví dụ thật, ≥1 CTA, meta đủ dài hợp lệ, không bịa số liệu.
