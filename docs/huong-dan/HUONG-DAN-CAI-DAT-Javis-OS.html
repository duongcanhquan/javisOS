1. Chọn đúng đường cài

Giải thích nhanh từng thứ
  • Python - lõi chạy server Javis trên máy (không dùng Docker).
  • Node.js - Claude Code / Codex / một số kết nối (Zalo…). Không có vẫn mở được app; thiếu khi bật CLI trên trang Models.
  • Git - kéo code bằng git clone; với ZIP thì không bắt buộc.
  • Docker - cách khuyến nghị trên VPS: Javis chạy trong container, không cần tự cài Python trên máy chủ.
  • ffmpeg - cắt/ghép audio-video (cuộc họp, render video). Docker image thường đã có; máy local thiếu thì một số tính năng media yếu hơn.
  • Ollama - chỉ khi muốn model AI chạy offline trên máy. Không bắt buộc.
Không cần GPU để cài và chat qua Claude/ChatGPT/OpenRouter. GPU chỉ hữu ích nếu bạn chủ động chạy Ollama model lớn hoặc công cụ clone giọng local nặng.

4. Máy cá nhân - Windows

4.1 Cài sẵn trên Windows (một lần - làm trước Javis)

  1. Python 3.11 hoặc 3.12 từ python.org/downloads/windows.
    • Trong installer: bắt buộc tick Add python.exe to PATH.
    • Nên chọn Disable path length limit nếu hiện.
    • Kiểm tra: mở cmd mới → gõ python --version (phải ≥ 3.11).
  2. Trình duyệt Chrome hoặc Edge (bản mới).
  3. Node.js 22 LTS từ nodejs.org (khuyến nghị). Kiểm tra: node -v.
  4. Git for Windows (khuyến nghị) từ git-scm.com nếu bạn clone repo thay vì ZIP.
  5. ffmpeg (tuỳ chọn, cho media): winget install Gyan.FFmpeg hoặc tải bản static rồi thêm vào PATH.
  6. Không tắt Windows Defender hoàn toàn; nếu chặn script .bat, chọn More info → Run anyway.
Xong mục 4.1 mới sang 4.2. Nếu python không nhận trong cmd, đóng hết cửa sổ rồi mở lại, hoặc cài lại Python và tick PATH.

4.2 Lấy Javis & cài

  1. Mở GitHub repo Javis → Code → Download ZIP → giải nén (ví dụ D:\Javis).
  2. Double-click 1-Cai-dat.bat (lần đầu vài phút).
  3. Thấy dòng http://localhost:7777 là xong.
  4. Mở Chrome/Edge → vào http://localhost:7777 → tạo tài khoản admin.

Hình 2. Luồng Windows: cài một lần → mỗi ngày bật → mở trình duyệt.

5. Máy cá nhân - macOS

5.1 Cài sẵn trên macOS (một lần - làm trước Javis)

  1. Xcode Command Line Tools (bắt buộc): mở Terminal → xcode-select --install → Accept. Không có bước này thì Python/Homebrew dễ lỗi.
  2. Python 3.11+: tải từ python.org/macos hoặc brew install python (sau khi có Homebrew).
  3. Homebrew (khuyến nghị): xem brew.sh. Giúp cài Node/ffmpeg nhanh.
  4. Node.js 22 LTS (khuyến nghị): nodejs.org hoặc brew install node@22. Kiểm tra node -v.
  5. ffmpeg (tuỳ chọn): brew install ffmpeg.
  6. Kiểm tra nhanh: python3 --version ≥ 3.11. Apple Silicon (M1/M2/M3) chạy tốt; không cần GPU.
Gatekeeper: lần đầu nên chuột phải → Open với file .command, không double-click nếu bị chặn.

5.2 Lấy Javis & cài

  1. Download ZIP từ GitHub → giải nén (ví dụ ~/Desktop/Javis).
  2. Chuột phải 1-Cai-dat.command → Open (macOS có thể hỏi nhà phát triển - chọn Open).
  3. Đợi xong → mở http://localhost:7777.
macOS chặn file .command? Chuột phải → Open → Open. Hoặc Cài đặt hệ thống → Quyền riêng tư & Bảo mật → Vẫn mở. Không double-click lần đầu trong Finder nếu bị chặn.

6. VPS Linux (Docker - khuyến nghị)

Phù hợp Ubuntu/Debian, Hostinger VPS, máy chủ 24/7. Image: ghcr.io/duongcanhquan/javisos:latest.

Hình 3. Kiến trúc VPS: trình duyệt → IP:7777 (hoặc HTTPS) → container Javis.

6.0 Cài sẵn trên VPS Linux (trước khi kéo Javis)

  1. SSH vào VPS từ máy bạn: ssh root@IP hoặc user ubuntu.
  2. OS khuyến nghị: Ubuntu 22.04/24.04 hoặc Debian 12. RAM ≥ 4 GB (khuyến nghị 8 GB).
  3. Cập nhật hệ thống: sudo apt update && sudo apt upgrade -y.
  4. Docker Engine + Compose plugin (bắt buộc với đường Docker). Không cần cài Python/Node trên host.
  5. Firewall / Security Group: mở TCP 22 (SSH) và 7777 (Javis). Nếu dùng HTTPS sau này: thêm 80/443.
  6. Tuỳ chọn sau: tên miền hoặc Cloudflare Tunnel nếu cần mic từ điện thoại (HTTPS).

6.1 Cài Docker trên VPS

curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER
# Đăng xuất SSH rồi đăng nhập lại
docker version
docker compose version

6.2 Chạy Javis (không tên miền - IP)

mkdir -p ~/javis && cd ~/javis
curl -fsSLO https://raw.githubusercontent.com/duongcanhquan/javisOS/main/docker-compose.yml
docker compose up -d
docker compose ps
Mở http://<IP-VPS>:7777. Firewall/security group phải mở TCP 7777 (và 22 cho SSH).

6.3 Hostinger Docker Manager (có HTTPS miễn phí)

  1. VPS → Docker Manager → Compose → URL.
  2. Dán: https://raw.githubusercontent.com/duongcanhquan/javisOS/main/docker-compose.hostinger.yml
  3. Đặt DOMAIN_NAME = javis.<hostname-vps>.hstgr.cloud (xem hostname trong hPanel).
  4. Deploy → mở https://…
Mic/giọng nói trên trình duyệt chỉ chạy với https:// hoặc localhost. Mở bằng http://IP:7777 từ máy khác thì mic bị chặn.

6.4 Cập nhật VPS

cd ~/javis
docker compose pull
docker compose up -d

7. VPS / máy chủ Windows

7.0 Cài sẵn trên VPS Windows (trước Javis)

  1. Đăng nhập máy chủ bằng Remote Desktop (RDP) hoặc SSH nếu có.
  2. Bật ảo hóa trong BIOS/UEFI nếu dùng Docker Desktop (WSL2 cần Hyper-V/Virtualization).
  3. Chọn một đường:
    • Docker Desktop (khuyến nghị): cài từ docker.com, bật WSL2, đợi icon xanh - không cần Python trên host.
    • Native: cài Python 3.11+ (tick PATH) + Node.js 22 LTS giống máy cá nhân.
  4. Windows Firewall: cho phép inbound TCP 7777 (và 3389 nếu RDP).
  5. Trình duyệt trên máy quản trị để mở http://IP:7777. Mic từ máy khác cần HTTPS.

7.1 Docker Desktop (gần giống Linux)

  1. Cài Docker Desktop (bật WSL2 nếu được hỏi). Đợi engine xanh.
  2. PowerShell:
mkdir $HOME\javis; cd $HOME\javis
Invoke-WebRequest -Uri https://raw.githubusercontent.com/duongcanhquan/javisOS/main/docker-compose.yml -OutFile docker-compose.yml
docker compose up -d
  1. Mở http://<IP>:7777. Windows Firewall: cho phép inbound TCP 7777.
  2. Cập nhật: docker compose pull rồi docker compose up -d.

7.2 Native Windows (không Docker, chạy 24/7)

  1. Giải nén gói như máy cá nhân → chạy 1-Cai-dat.bat.
  2. javis-autostart.bat install để tự bật khi đăng nhập.
  3. Cho Javis lắng nghe mạng (0.0.0.0) - xem tài liệu cấu hình env.
  4. Khi chạy public: bắt buộc đặt mật khẩu admin mạnh.

8. Thiết lập lần đầu trong app (mọi đường)

Hình 4. Thứ tự sau khi mở app lần đầu.

  1. Tài khoản admin - đặt mật khẩu (bắt buộc trên VPS công khai).
  2. Models - chọn bộ não: Claude Code / ChatGPT / Antigravity / API key…
  3. Kết nối (tuỳ chọn) - Gmail, Calendar, Zalo, Ads…
  4. Vào Chat - hỏi thử một câu.

Chi tiết dùng hàng ngày: xem PDF Hướng dẫn sử dụng Javis OS (cùng thư mục).
