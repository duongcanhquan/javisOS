1. Javis là gì?

Javis là trợ lý AI chạy trên máy bạn hoặc VPS. Bạn chọn “bộ não” (Claude, ChatGPT, Gemini…), kết nối dữ liệu thật (email, lịch, Drive, Zalo…), và làm việc trong một giao diện.

Hình 1. Bạn chat → Javis gọi bộ não + dữ liệu đã kết nối + tri thức trong brain.

Javis làm được
  • Trả lời, tóm tắt, lập kế hoạch
  • Đọc số liệu từ kết nối (nếu có)
  • Ghi nhớ / lưu note / skill
  • Nhắc việc, việc nền (khi bật)
Javis không phải
  • Không tự biết mật khẩu của bạn
  • Không có số liệu nếu chưa kết nối
  • Không thay bạn duyệt mọi rủi ro tiền bạc
  • Không “nhớ mãi” nếu bạn không lưu

3. Năm phút đầu tiên

  1. Mở Javis (localhost:7777 hoặc link VPS) → đăng nhập / tạo admin.
  2. Vào Models → chọn một bộ não → đăng nhập hoặc dán API key → chọn Main Model.
  3. Về Chat → gõ: “Xin chào, bạn có thể làm gì cho tôi?”
  4. (Tuỳ chọn) Vào Kết nối gắn 1 nguồn thật (Gmail hoặc Calendar).
  5. Hỏi lại một câu có dữ liệu: “Tóm tắt email quan trọng hôm qua” (nếu đã nối Gmail).
Nếu chưa nối gì, Javis vẫn chat được - chỉ chưa đọc được số liệu bên ngoài.

4. Chat hiệu quả

Hình 3. Câu hỏi càng cụ thể, câu trả lời càng dùng được ngay.

Gửi file: đính kèm trong chat để Javis đọc và trả lời. Chỉ khi bạn nói “lưu vào source / second brain” thì mới ingest vào tri thức.

5. Bộ não (Models)

Javis không gắn một hãng AI. Bạn chọn engine trên trang Models. Năng lực MCP / skill / tệp giống nhau giữa các engine; khác chủ yếu ở shell / web search (nhóm CLI).

NhómVí dụBạn cần
Subscription CLIClaude Code, ChatGPT Codex, Grok Build, AntigravityĐăng nhập gói đã có
API keyOpenRouter, OpenAI, Gemini, DeepSeek…Dán key trên Models
Chạy nền 24/7 trên VPS bằng gói Pro/Max cá nhân có rủi ro khóa tài khoản. An toàn hơn: API key hoặc model nền riêng.

6. Kết nối dữ liệu

Hình 4. Kết nối = ống dẫn dữ liệu. Chưa nối thì Javis không bịa số.

  1. Vào Kết nối → chọn dịch vụ → làm theo nút (OAuth / key / QR).
  2. Quay lại Chat, hỏi đúng việc liên quan nguồn đó.

7. Bộ não tri thức & tệp

Mỗi brain là một kho markdown (notes, wiki, sources). Trang Tệp tin để mở/sửa. Project (dự án chat) thuộc đúng một brain.

Nên làm
  • Lưu quyết định quan trọng vào memory khi bảo “nhớ giúp”
  • Ingest từng file quan trọng, không nhồi cả kho một lần
Tránh
  • Đưa mật khẩu / key vào chat rồi quên xoá
  • Trộn nhiều dự án lẫn lộn một brain nếu muốn tách riêng

Javis không “để đó rồi tự quay lại tóm tắt” sau khi bạn tắt chat. Việc nền đẩy kết quả vào hộp chat / chuông / Work - hoặc bạn hỏi lại sau.

9. Mẹo & tránh nhầm

  1. Một câu = một mục tiêu rõ.
  2. Muốn số liệu thật → kiểm tra Kết nối trước.
  3. Mic chỉ trên localhost hoặc https://.
  4. Cập nhật: máy local kéo bản mới / VPS docker compose pull.
  5. Đọc thêm PDF Hướng dẫn cài đặt nếu đổi máy hoặc sang VPS.
Checklist ngày đầu: Models OK · Chat thử OK · (tuỳ chọn) 1 Kết nối · biết mở Tệp tin.
